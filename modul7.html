Lingkaran

Definisi dan unsur-unsurnya: jelajahi, geser, dan ubah sendiri pada bidang koordinat.

1. Definisi2. Unsur-unsur3. Persamaan4. Kuis

1. Definisi Lingkaran

Geser titik P dan geser slider jari-jari untuk melihat apa yang membuat sebuah titik “berada pada lingkaran”.

Lingkaran adalah himpunan semua titik pada bidang yang berjarak sama terhadap sebuah titik tetap. Titik tetap itu disebut pusat, dan jarak tersebut disebut jari-jari (r).
L = { P(x, y) | OP = r }
OP = 0

Pusat O(0, 0). Titik P berada pada lingkaran jika OP = r, di dalam jika OP < r, dan di luar jika OP > r.

2. Unsur-unsur Lingkaran

Pilih unsur pada tombol, atau klik langsung bagian gambarnya.

Pilih sebuah unsur
Setiap unsur akan disorot pada gambar beserta penjelasan dan rumusnya.

3. Persamaan Lingkaran

Ubah pusat (a, b) dan jari-jari r. Perhatikan bagaimana persamaannya ikut berubah.

Rangkuman rumus

Bentuk baku: (x − a)² + (y − b)² = r², pusat (a, b), jari-jari r.
Pusat di O: x² + y² = r².
Bentuk umum: x² + y² + Ax + By + C = 0 dengan pusat (−A/2, −B/2) dan r = √(A²/4 + B²/4 − C).
