Tujuan Pembelajaran

  • Menyusun persamaan berkas lingkaran dan menentukan anggotanya.
  • Menentukan garis kuasa dua lingkaran.
  • Menentukan syarat dua lingkaran saling ortogonal dan menerapkannya.
Bentuk umum lingkaran dalam modul ini: x² + y² + Ax + By + C = 0, dengan pusat (−A/2, −B/2) dan r² = A²/4 + B²/4 − C.

1. Berkas Lingkaran

Misalkan dua lingkaran:

L₁ : x² + y² + A₁x + B₁y + C₁ = 0    L₂ : x² + y² + A₂x + B₂y + C₂ = 0

Berkas lingkaran adalah himpunan semua lingkaran yang persamaannya berbentuk

L₁ + λL₂ = 0,   λ ≠ −1

Setiap anggota berkas melalui titik-titik potong L₁ dan L₂ (jika ada), sebab titik yang memenuhi L₁ = 0 dan L₂ = 0 otomatis memenuhi kombinasi keduanya.

Garis kuasa. Untuk λ = −1 suku kuadratnya saling meniadakan dan diperoleh garis
(A₁ − A₂)x + (B₁ − B₂)y + (C₁ − C₂) = 0
yang disebut garis kuasa. Garis ini tegak lurus garis yang menghubungkan kedua pusat. Jika kedua lingkaran berpotongan, garis kuasa memuat kedua titik potong.

Variasi berkas

JenisPersamaan
Dua lingkaranL₁ + λL₂ = 0
Lingkaran dan garis g = 0L + λg = 0 (melalui titik potong L dan g)
Berkas konsentrisx² + y² + Ax + By + k = 0, k berubah

Langkah menentukan anggota berkas yang memenuhi syarat: (1) tulis L₁ + λL₂ = 0; (2) substitusi titik atau syarat yang diketahui untuk mencari λ; (3) masukkan λ ke persamaan berkas dan sederhanakan.

Simulasi 1: Berkas Lingkaran

Atur L₁ dan L₂, lalu geser λ. Garis putus-putus adalah garis kuasa.

Hijau: L₁ dan L₂ · Jingga: anggota berkas · Putus-putus: garis kuasa. L₁ berpusat di (−1,5; 0).

2. Lingkaran Ortogonal

Dua lingkaran disebut ortogonal jika berpotongan di dua titik dan garis singgung keduanya di setiap titik potong saling tegak lurus. Artinya, jari-jari kedua lingkaran di titik potong juga saling tegak lurus.

Syarat geometri. Pada segitiga siku-siku dengan sisi r₁, r₂, dan jarak pusat d:
d² = r₁² + r₂²
Syarat aljabar. Untuk L₁ dan L₂ bentuk umum di atas:
A₁A₂ + B₁B₂ = 2(C₁ + C₂)

Asal-usul. d² = (A₁−A₂)²/4 + (B₁−B₂)²/4. Samakan dengan r₁² + r₂² = (A₁²+B₁²+A₂²+B₂²)/4 − C₁ − C₂. Suku kuadrat saling habis dan tersisa −(A₁A₂+B₁B₂)/2 = −(C₁+C₂), yaitu syarat di atas.

Simulasi 2: Uji Ortogonalitas

L₁ berpusat di titik asal. Geser L₂ dan perhatikan nilai d² dibandingkan r₁² + r₂².

3. Contoh Soal

Contoh 1 — Berkas melalui titik tertentu

Tentukan persamaan lingkaran yang melalui titik potong x² + y² − 4x = 0 dan x² + y² − 4y = 0 serta titik (0, −2).

Berkas: (x²+y²−4x) + λ(x²+y²−4y) = 0. Substitusi (0, −2): 4 + λ(12) = 0, jadi λ = −1/3. Kalikan 3: 3(x²+y²−4x) − (x²+y²−4y) = 0, yaitu

x² + y² − 6x + 2y = 0
Contoh 2 — Garis kuasa

Garis kuasa x² + y² − 4x = 0 dan x² + y² − 4y = 0: kurangkan keduanya, −4x + 4y = 0, sehingga garis kuasanya y = x.

Contoh 3 — Syarat ortogonal

Tentukan k agar x² + y² + 4x − 2y + k = 0 ortogonal dengan x² + y² − 2x − 4y + 1 = 0.

A₁A₂ + B₁B₂ = (−2)(4) + (−4)(−2) = 0, maka 0 = 2(1 + k), sehingga k = −1.

Pemeriksaan: pusat (1, 2) dengan r₁² = 4, pusat (−2, 1) dengan r₂² = 6, d² = 9 + 1 = 10 = 4 + 6. ✓
